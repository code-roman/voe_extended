# VOE: мої адреси

Користувацький скрипт для [сайту відключень ВОЕ](https://disconnection.voe.com.ua/): показує графіки кількох адрес і рахунків в одному місці та підсвічує зміни з минулого перегляду. Адреси зберігаються лише у вашому браузері.

**Як встановити:** [покрокова інструкція](https://code-roman.github.io/voe_extended/). Потрібен комп'ютер із Chrome або Edge.
